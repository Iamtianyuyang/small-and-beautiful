# 发布前检查清单

逐项过一遍，任何一项不过都先修，修完再发布。

## 聚焦
- [ ] 一句话能说清这个产品做什么
- [ ] 核心功能不超过 3 个，没有"顺手加的"功能
- [ ] 每个设置项都删不掉（删掉就要有一个好的默认值替代）

## 第一印象
- [ ] 打开后第一屏就能开始用，没有强制注册、引导页、弹窗
- [ ] 冷启动 < 1s，首屏没有闪烁和布局跳动
- [ ] 应用图标与名称经得起放在手机主屏或 Dock 上看

## 视觉
- [ ] 只有一个强调色，且只出现在主操作和选中态
- [ ] 间距全部落在 4/8pt 网格上，圆角只有一套
- [ ] 能去掉的边框和分割线已经去掉
- [ ] 图标风格统一，描边宽度一致
- [ ] 深色模式逐屏检查过，不是简单反色

## 文字
- [ ] 中英文、数字之间有空格，中文用全角标点
- [ ] 行高、行长舒适，没有两端对齐撑出的大空隙
- [ ] 按钮都是动词，没有"确定""好的"
- [ ] 文案没有错别字、没有机翻腔

## 交互与动效
- [ ] 每个可点元素都有按下态和禁用态
- [ ] 耗时操作有进度提示，完成后有确认
- [ ] 危险操作支持撤销，或至少有二次确认
- [ ] 动效时长 150–300ms，方向符合逻辑，遵守"减少动态效果"设置
- [ ] 键盘可用（桌面端/Web），触控目标不小于 44×44（移动端）

## 边界状态
- [ ] 空状态：有温度的一句话 + 一个动作
- [ ] 错误状态：说明发生了什么、该怎么办，没有裸露的错误码
- [ ] 加载状态：骨架屏或进度提示，没有长时间白屏
- [ ] 断网、超长文本、超大数据、极小窗口都试过

## 尊重
- [ ] 没有广告，没有诱导点击，没有默认勾选的"同意"
- [ ] 只申请必需的权限，并在用到时才申请
- [ ] 数据本地优先，可以完整导出
- [ ] 没有不必要的统计上报

## 工程
- [ ] 每个依赖都说得出理由，没有用不上的依赖
- [ ] 包体积和首屏资源在预算内
- [ ] 删掉了死代码、调试日志和临时注释

## 最后 1%
- [ ] 找到至少一个"会心一笑"的细节
- [ ] 自己愿意把它截图发给朋友
