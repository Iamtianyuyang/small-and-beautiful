# Self-check

The last pass before handing off. This checks the document itself, not the product.

- [ ] Each rule is defined once; no later section introduces a conflicting second value
- [ ] A cut feature does not reappear later under "risks", "easter eggs", or "later"
- [ ] Every recommendation states a reason for this product, not a restatement of a principle; swap the product and the reason no longer holds
- [ ] Every state message (empty, loading, error, done) says when it appears and when it disappears, not just the sentence
- [ ] The numbers add up: rows × row height + header + toolbar + footer ≤ screen height
- [ ] Mutually exclusive mechanisms do not coexist: pagination and virtual scrolling, undo and no-undo, two densities; one thing has one mechanism
- [ ] Every named UI region (including invented names) has its states defined
- [ ] Every number that appears (font size, spacing, milliseconds, money) has a use somewhere in the same document
