# grid-design source assets

Original PSD templates and GIF diagrams from [ColdXu/grid-design](https://github.com/ColdXu/grid-design), kept for reference.

- `templates/` — 12-column Photoshop overlays for 750 / 720 / 940 / 1140 px canvases.
- `diagrams/` — the four canvases and span comparisons.

The upstream repository has no license file. These files are included with attribution for reference only; confirm permission with the original author before redistributing them. The installed skill ships SVG equivalents, not these binaries. See `skills/sab-grid-design/references/source-notes.md` for dimensions, rules, and attribution.
